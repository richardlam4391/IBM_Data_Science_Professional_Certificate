# Machine Learning with Python

## Title: Building a Rainfall Prediction Classifier

**Machine Learning with Python** contains implementing, evaluating, and tuning supervised and unsupervised algorithms using the Python data science stack. This is completed in October 2025.

The project demonstrates to complete Machine Learning workflow—spanning feature engineering, algorithm training, mathematical optimization, and rigorous statistical evaluation.

---
## Core Tasks

- Use Python library, which is Scikit-learn, to train each model classification.
- Use Grid Search or Random Search to optimize model performances and hyperparameters.
- Generate a treemap or confusion matrix to evaluate a good predictor of rainfall.

---

## Core Objectives:
1. **Data Preprocessing & Encoding:** Convert categorical attributes via one-hot encoding, handle class imbalances, and apply feature scaling.
2. **Supervised Learning Classification:** Build and fine-tune K-Nearest Neighbors (KNN), Decision Trees, Support Vector Machines (SVM), and Logistic Regression models.
3. **Hyperparameter Tuning:** Leverage train-test splits and cross-validation grids to maximize generalization capability.
4. **Comparative Evaluation:** Evaluate models using industry-standard metrics to determine production readiness.

---

## Tech Stack & Core Libraries
* **Machine Learning Engine:** `Scikit-Learn`
* **Mathematical Operations:** `NumPy`, `SciPy`
* **Data Ingestion & Transformation:** `Pandas`
* **Evaluation Visualizations:** `Matplotlib`, `Seaborn`
